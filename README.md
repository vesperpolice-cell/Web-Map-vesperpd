# 🗺️ VES-PD MAP — เว็บแผนที่แยกเดี่ยว

แยกออกมาจาก `Web-VES-PD-PD-0.1/map-module/` โดยเก็บไฟล์ในโมดูลไว้เหมือนเดิมทั้งหมด
**ยกเว้น 3 จุด** — ถ้าก๊อป map-module จากเว็บหลักมาทับเมื่อไหร่ ต้องแก้ 3 จุดนี้กลับทุกครั้ง
ไม่งั้นเว็บพัง (รายละเอียดใน [ไฟล์รูปเป็น WebP](#ไฟล์รูปเป็น-webp)):

| ไฟล์ | แก้อะไร | ถ้าไม่แก้กลับ |
|---|---|---|
| `server/poi-routes.js` | `scanCustomIcons()` รับ `.webp` ด้วย + กันข้อมูลชีตหาย | หมุดหลุดหมวดทั้งแผนที่ |
| `Challenge/src/game-core.js` | tile URL 2 จุดเป็น `.webp` | หน้า `/Challenge` แผนที่จอดำ |
| `Challenge/game.html` | `logo.gif` → `logo.webp` | โลโก้ในเกมเป็นรูปแตก |

ส่วนหน้าแผนที่หลักไม่ต้องแก้ในโมดูล — `public/map.html` ส่ง `styleExts` เป็น options
เข้า `VESPD_MAP.init()` เอาเอง (ดูหัวข้อ [ข้อมูล POI](#ข้อมูล-poi) — `poi-routes.js`
แก้เหมือนกันทั้งเว็บนี้และเว็บหลัก)

## เริ่มใช้งาน

```bash
npm install
npm start          # หรือ npm run dev (auto-reload)
```
เปิด http://localhost:3001 → redirect ไป `/MapVesperPD`

| เส้นทาง | ใช้ทำอะไร |
|---|---|
| `/MapVesperPD` | หน้าแผนที่หลัก |
| `/Challenge` | เกมทายตำแหน่ง 50 จุด |
| `/api/poi` | GET เปิดให้ทุกคน · POST/PUT/DELETE ต้องใส่รหัสก่อน |
| `/api/poi/categories` | หมวดหมู่ (สแกนจากไฟล์ไอคอนใน `map-module/blips/custom/`) |
| `/api/poi/visibility` | GET อ่านสถานะสวิตช์ซ่อนจุด · POST สลับ (ต้องใส่รหัส) |
| `/api/auth/pin` | GET เช็คสถานะ · POST ส่งรหัสมาปลดล็อก |
| `/api/auth/logout` | ล็อกกลับ |

## 🔐 ระบบรหัส 4 หลัก

ดูแผนที่ ค้นหา กรอง และเล่นเกม ได้โดยไม่ต้องใส่รหัส
จะ **เพิ่ม / แก้ไข / ลบจุด** ต้องกดปุ่ม **"ใส่รหัสเพื่อแก้ไข"** มุมบนของแถบด้านขวาก่อน

ตั้งรหัสที่ `ADMIN_PIN` ใน `.env`

**เช็คสองชั้น:**
1. **ฝั่งหน้าเว็บ** — `public/src/map-pin.js` ซ่อนปุ่ม ✎ / ✕ และปิดการคลิกลงจุด
2. **ฝั่งเซิร์ฟเวอร์** — `server/pin-auth.js` ตอบ `401` ถ้า POST/PUT/DELETE เข้ามาโดยไม่มีสิทธิ์
   → ต่อให้ยิง `curl` ตรงๆ ก็ลบจุดไม่ได้

หลังใส่รหัสถูก เซิร์ฟเวอร์จะออก session token ส่งกลับเป็น **cookie แบบ HttpOnly**
(JavaScript อ่านไม่ได้ เบราว์เซอร์แนบให้เองทุก request) อายุ 8 ชั่วโมง เก็บในหน่วยความจำ
— **รีสตาร์ทเซิร์ฟเวอร์ = ทุกคนต้องใส่รหัสใหม่**

ใส่รหัสผิดได้ 8 ครั้งต่อ 10 นาทีต่อ IP แล้วจะโดนบล็อก (`429`)

## ⚠️ ทำไมโครงโฟลเดอร์ต้องเป็นแบบนี้

`map-module/server/poi-routes.js` hardcode path ที่เอื้อมออกนอกโมดูลไว้ **ห้ามย้ายโฟลเดอร์เหล่านี้**:

```
poi-routes.js  →  require('../../server/config')                        →  server/config/index.js
poi-routes.js  →  path.join(__dirname,'..','..','data','poi-cache.json') →  data/poi-cache.json
map.html       →  /logo.webp                                            →  public/logo.webp
```

**และ `public/src/map-pin.js` ต้องประกาศ global ชื่อ `VESPD_DC`** เพราะ `map-module/src/map-poi.js`
เรียก `VESPD_DC.canAdd()` / `canEdit()` / `isConnected()` / `getDcId()` / `setAuthorizedIds()` อยู่
— เปลี่ยนชื่อเมื่อไหร่แผนที่พังทันที

`/MapVesperPD` เสิร์ฟ **`public/map.html` ของเว็บนี้** (ไม่ใช่ `map-module/public/map.html`)
ไฟล์นี้ก๊อปมาจากของเดิมแล้วเปลี่ยนแค่ 3 จุด: ตัดบล็อกเชื่อม Discord ออก → ใส่ปุ่มรหัสแทน,
เพิ่ม `map-pin.css`, และสลับสคริปต์ auth เป็น `map-pin.js`

## 🔑 Environment (ไฟล์เดียวจบ — ไม่มี credentials.json)

```
PORT=3001
ADMIN_PIN=
SHEET_ID=<id ของ Google Sheet>
GOOGLE_JSON_KEY='<service account JSON บรรทัดเดียว>'
```

Service account อยู่ใน `.env` เป็นตัวแปร `GOOGLE_JSON_KEY` — `server/config/googleAuth.js`
เช็ค env ตัวนี้ก่อนไฟล์ `credentials.json` อยู่แล้ว จึงไม่ต้องมีไฟล์นั้น

สร้างค่าจาก `credentials.json` เดิม:
```bash
node -p "\"GOOGLE_JSON_KEY='\" + JSON.stringify(require('./credentials.json')) + \"'\""
```

> **⚠️ ต้องเป็นบรรทัดเดียว และครอบด้วย single quote `'...'` เท่านั้น**
> ถ้าใช้ double quote `"..."` → dotenv จะแปลง `\n` ใน `private_key` เป็นขึ้นบรรทัดจริง
> แล้ว `JSON.parse` จะพังด้วย `Bad control character in string literal`
> (บน Render วาง JSON ดิบๆ ไม่ต้องใส่ quote — Render ไม่ได้ parse แบบ dotenv)

## ข้อมูล POI

เก็บใน Google Sheet **เดียวกับเว็บหลัก** (ชีตชื่อ `MapPOI`) → จุดบนสองเว็บ sync กันตลอด
คอลัมน์ A–G = `id`, `name`, `category`, `description`, `x`, `y`, `createdAt`
คอลัมน์ J = `dcId` (ถ้ามี)

> **H1 / I1 ถูกจองให้สวิตช์โหมดสอบ** — `H1 = POI_VISIBILITY`, `I1 = VISIBLE` หรือ `HIDDEN`
> ห้ามใช้คอลัมน์ H–I เก็บข้อมูลจุด (ตารางจริงมีแค่ A–G + `dcId` ที่ J)
> `POST /api/poi/repair` เขียนใหม่เฉพาะ A–G (+J) และไฟล์สำรองอ่าน A:K แบบอ่านอย่างเดียว
> → ค่า flag ไม่หายไปไหน

ถ้าต่อ Google Sheets ไม่ได้ ระบบจะ fallback ไปอ่าน [data/poi-cache.json](data/poi-cache.json) อัตโนมัติ

### 🛡️ บั๊กที่เคยทำข้อมูลหายทั้งแผ่น — แก้แล้ว

ข้อมูลในชีตเคยหายไปทั้ง 413 จุดมาแล้วจริง Drive revision history ยืนยันว่าคนเขียนทับคือ
**service account** ไม่ใช่คน แปลว่าโค้ดของระบบลบเอง แก้ใน `map-module/server/poi-routes.js`
ไป 3 จุด (ทั้งเว็บนี้และเว็บหลัก เพราะชี้ Google Sheet ใบเดียวกัน):

**1. ปิด auto-repair ที่รันเองทุกครั้งที่เซิร์ฟเวอร์เริ่มทำงาน** (IIFE ท้ายไฟล์)
เดิมคือ "เปิดเว็บ 1 ครั้ง = แตะข้อมูลจริง 1 ครั้ง" โดยไม่มีใครสั่ง
ระบบรหัสกันจุดนี้ไม่ได้ เพราะมันรันตอน mount router ก่อนจะมี HTTP request ใดๆ
ถ้าต้องการซ่อมชีตจริงๆ ให้เรียกมือผ่าน `POST /api/poi/repair` (ต้องใส่รหัสก่อน)

**2. เปลี่ยนลำดับจาก "ล้างก่อน–เขียนทีหลัง" เป็น "เขียนก่อน–ล้างส่วนเกินทีหลัง"**
ของเดิมสั่ง `values.clear('MapPOI!A:G')` แบบไม่มีเงื่อนไข แล้วค่อยเขียนกลับแบบ **มี** เงื่อนไข
→ ถ้าอ่านข้อมูลไม่ออกสักแถว ก็ล้างทิ้งแล้วไม่เขียนอะไรคืนเลย
ตอนนี้ถ้าอ่านไม่ออกจะ `skipped` ทันทีโดยไม่แตะชีต และล้างเฉพาะแถวส่วนเกินท้ายตาราง
หลังเขียนข้อมูลเสร็จแล้ว → ไม่มีช่วงเวลาที่ชีตว่างอีกต่อไป

**3. เลิกใช้ `values.append` — ต้นตอที่แท้จริงของเรื่องทั้งหมด**
`append` ให้ Google "เดา" ขอบเขตตารางเอง พอชีตนี้มีข้อมูลอื่นอยู่คอลัมน์ I/J ด้วย
มันเคยเดาผิดแล้วเขียนจุดใหม่ลงคอลัมน์ **D–K** แทน A–G
แถวที่เพี้ยนจะมีคอลัมน์ A ว่าง → `repairSheet` มองเป็นขยะ → พอเพี้ยนครบทุกแถวก็ลบเกลี้ยง

ตอนนี้ `POST /api/poi` อ่านคอลัมน์ A เพื่อหาเลขแถวถัดไป แล้วเขียนลง `A{n}:G{n}` ตรงๆ
**ไม่มีการเดาอีกต่อไป** — และ `dcId` (ถ้ามี) ก็ลง `J{n}` แถวเดียวกัน ไม่ใช่แถวที่คำนวณผิดแบบเดิม

> เพราะแก้ที่โค้ดได้ จึง **ไม่ต้องไปรื้อ Google Sheet ของจริงเลย** คอลัมน์ J ที่เหลืออยู่
> กลายเป็นข้อมูลเก่าที่ไม่มีพิษภัยแล้ว จะลบหรือเก็บไว้ก็ได้

**เว็บหลัก (`Web-VES-PD-PD-0.1`)** แก้ 3 จุดข้างบนเหมือนกัน และเพิ่มอีกชั้น:
`/api/poi` ที่นั่นเป็น **อ่านอย่างเดียว** แล้ว (POST/PUT/DELETE ตอบ `403`)
เดิมมันเปิดทิ้งไว้ไม่มีการตรวจสิทธิ์เลย ใครก็ยิง `DELETE /api/poi/:id` ลบจุดได้
ตอนนี้แก้จุดได้ที่เว็บแผนที่ซึ่งมีรหัสผ่านที่เดียว

## 🕶️ สวิตช์ซ่อนจุดทั้งแผนที่ (โหมดสอบ)

ใส่รหัสแล้ว **โลโก้ในแถบขวาจะกลายเป็นปุ่มรูปตา** (ซ้ายมือของปุ่มรหัส) กดเพื่อซ่อน/เปิดจุดให้คนทั่วไป
ปุ่มเป็นสีฟ้า = คนทั่วไปเห็นจุด · สีแดง = ซ่อนอยู่

การซ่อนทำที่ **server** ไม่ใช่ซ่อนด้วย JavaScript — ตอนปิด `/api/poi` คืน `[]` ออกไปเลย
เปิด URL ตรง ๆ ก็ไม่เห็น และเกม `/Challenge` ปิดตามอัตโนมัติเพราะดึงจุดจาก API เดียวกัน
**คนที่ใส่รหัสแล้วยังเห็นจุดครบตามเดิม** จะได้คุมสอบไปแก้แผนที่ไปได้

| | |
|---|---|
| โค้ด | [server/poi-visibility.js](server/poi-visibility.js) + [public/src/map-visibility.js](public/src/map-visibility.js) |
| เก็บสถานะ | ชีต `MapPOI` — **H1** = `POI_VISIBILITY` (ป้าย) และ **I1** = `VISIBLE` / `HIDDEN` (ค่า) — ไม่มีแท็บ `Settings` แล้ว |
| cache | 15 วินาทีในหน่วยความจำ กันไม่ให้ทุก request ยิง Sheets เพิ่ม |

**ข้อควรรู้**

- ไฟล์นี้อยู่นอก `map-module` โดยตั้งใจ เสียบเป็น middleware คั่นหน้า `poi-routes`
  จึงไม่ต้องแก้อะไรในโมดูลเพิ่มจาก 3 จุดที่มีอยู่
- **อ่านสถานะไม่ได้ = ถือว่าปิดไว้ก่อน** เพราะ `poi-routes.js` มี fallback ไปอ่าน
  `poi-cache.json` เวลา Sheets ล่ม ถ้าปล่อยให้ fail open ตอนสอบแล้วชีตล่ม ข้อมูลจะหลุดทั้งชุด
  (ยกเว้นกรณีที่ยังไม่เคยตั้งค่าเลย — `I1` ว่าง หรือยังไม่มีชีต `MapPOI` อันนั้นนับเป็น "เปิด")
- **ระบบไม่สร้างชีต/แท็บใด ๆ** — เขียนเฉพาะ `MapPOI!I1` (และเติม `H1` ให้ถ้ายังว่าง) ไม่แตะ A–G เลย
  ถ้าชีต `MapPOI` ยังไม่มี ปุ่มตาจะได้ `409` พร้อมข้อความบอก (สร้างชีตได้ด้วยการเพิ่มจุด POI จุดแรก)
  — ไม่มีแท็บ `Settings` เกิดขึ้นอีก
- **คนที่เปิดหน้าเว็บค้างไว้ก่อนกดปิด จะยังเห็นจุดบนจอจนกว่าจะรีเฟรช** — ไม่มี auto-refresh
  ให้กดปิดก่อนเริ่มสอบสักพัก และกันคนที่แคปหน้าจอไว้ล่วงหน้าไม่ได้

| ของ | ก่อน | หลัง |
|---|---|---|
| map tile 2,730 ไฟล์ | 50.5 MB | 11.1 MB (−78%) |

แปลงด้วยสคริปต์ใน `scripts/` (`convert-tiles.js`, `convert-blips.js`, `convert-logo.js`)
รันครั้งเดียวแล้ว commit — ไม่ได้ทำตอน build และไม่ได้ใส่ `sharp` ใน `package.json`
วิธีรันอยู่ในหัวไฟล์สคริปต์

**สิ่งที่ต้องระวัง**

- `scanCustomIcons()` ใน `poi-routes.js` เอาชื่อไฟล์ที่ตัดนามสกุลออกไปเป็น **category id**
  ซึ่งเป็นค่าเดียวกับที่เก็บในชีต `MapPOI` → **เปลี่ยนได้แค่นามสกุล ห้ามเปลี่ยนชื่อไฟล์**
- ยังเก็บ `blips/custom/2mark.png` ไว้ เพราะ `map-core.js` (ไฟล์ต้นฉบับจากเว็บหลัก)
  hardcode fallback เป็น `'2mark.png'` และหมวด `1mark` ที่ไม่มีไฟล์ไอคอน
  (~135 จุด) ตกมาใช้ตัวนี้ทั้งหมด
- `styleSatelite/satellite.jpg` (8192×8192, 10.5 MB) และ `style*/empty.jpg`
  ไม่ใช่ tile ไม่มีโค้ดไหนเรียก จงใจไม่แปลง — แต่ยังถูกก๊อปเข้า `dist/` ทุก deploy

```bash
git log --format="%h %an %s" -10     # ดู author ทีละคอมมิต
```

remote มีสองตัว ชี้ repo คนละที่ — push ให้ครบทั้งคู่:

| remote | repo |
|---|---|
| `origin` | `lonewolf259999-cell/Wed-Map-Mhnk-PD` |
| `man2599` | `man2599/wed-map-mhnk-pd` |

> ⚠️ **ห้ามเอาบัญชีนี้ไปยุ่งกับเว็บหลัก** (`mhnk-pd.online`) — คนละบัญชี Vercel กัน

## Deploy (Render)

ใช้ [render.yaml](render.yaml) ได้เลย — ตั้ง env vars ในหน้า dashboard:
`ADMIN_PIN`, `SHEET_ID`, `GOOGLE_JSON_KEY`

## โครงสร้าง

```
map/
├── server/
│   ├── index.js              ← เขียนใหม่สำหรับเว็บนี้
│   ├── pin-auth.js           ← ระบบรหัส 4 หลัก (session + cookie + middleware)
│   ├── poi-backup.js         ← สำรองชีตลงไฟล์ตอน start (อ่านอย่างเดียว)
│   ├── config/index.js       ← ตัดจากเว็บหลัก เหลือเฉพาะที่แผนที่ใช้
│   ├── config/googleAuth.js  ← ก๊อปจากเว็บหลัก (ไม่แก้)
│   └── utils/logger.js       ← ก๊อปจากเว็บหลัก (ไม่แก้)
├── public/
│   ├── map.html              ← หน้าแผนที่ของเว็บนี้ (ปุ่มรหัสแทนปุ่มเชื่อมบัญชี)
│   ├── logo.webp
│   └── src/
│       ├── map-pin.js        ← ประกาศ global VESPD_DC (ห้ามเปลี่ยนชื่อ)
│       └── map-pin.css
├── data/
│   ├── poi-cache.json        ← fallback ตอนต่อ Sheets ไม่ได้
│   └── poi-backup-*.json     ← สำรองอัตโนมัติ เก็บ 7 ไฟล์ล่าสุด
└── map-module/               ← ก๊อปมาจากเว็บหลัก แก้ 3 จุด (ดูหัวตาราง README)
```
